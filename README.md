인스타그램 프로젝트

## DB 구조
유저(email 기반)
- 소셜 로그인
- 팔로우, 팔로워 (팔로잉 기능)

## 포스트(블로그 형식)
1. 댓글 기능
2. 라이크(좋아요 기능)
3. 태그 기능
   
## 기능
회원관련
- 회원 가입, 로그인, 로그아웃, 아이디 / 비밀번호 찾기
- 소셜로그인
- 팔로우 기능(연결, 해제)
- 팔로우/팔로워 수 및 목록 조회

포스트 
- 포스트 생성, 수정, 삭제, 나만보기(친한사람만 허용) / 태그기능
- 댓글 작성, 수정, 삭제
- 라이크
- 무한스크롤 기능(포스트, 댓글)

## 추가기능
- DM, 릴스, 이미지 업로드, 수정, 효과보정 등
